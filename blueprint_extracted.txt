Blueprint Teknis Koran Digital Magelang Ekspres
Halaman 3
1. Ringkasan Eksekutif
Koran Digital Magelang Ekspres harus dibangun sebagai ekosistem media digital berlangganan, bukan
sekadar website berita atau aplikasi baca PDF. Produk inti mencakup aplikasi mobile, website responsif,
CMS redaksi, sistem langganan, e-paper harian, mode baca artikel, paywall, dan keamanan konten
premium.
Model akses yang dipakai adalah freemium-paywall: pengunjung umum bisa melihat judul, ringkasan,
kategori, thumbnail blur, dan ajakan berlangganan; pelanggan aktif dapat membuka artikel penuh, foto
tanpa blur, e-paper, mode baca, arsip, download PDF, dan fitur personal.
Dokumen ini memecah rancangan ke dalam spesifikasi teknis agar tim IT dapat mulai membuat
database migration, API endpoint, tampilan mobile, website, CMS, sistem pembayaran, dan skenario
testing tanpa menafsirkan ulang konsep dari awal.
Output produk final
 - Aplikasi Android dan iOS yang dapat dipromosikan di Play Store dan App Store.
 - Website berita responsif dan SEO-ready.
 - CMS redaksi untuk artikel, kategori, headline, topik hangat, e-paper, langganan, pembayaran, dan
 notifikasi.
- Paywall premium dengan aktivasi langganan otomatis.
 - E-paper dengan viewer halaman, mode artikel, daftar artikel, download PDF, watermark, dan signed
 URL.
- Dashboard analitik untuk redaksi, pelanggan, transaksi, download, dan performa artikel.

7. Paywall, Subscription, dan Pembayaran
7.1 Paywall server-side
Paywall harus divalidasi di backend. Frontend hanya menampilkan status hasil validasi. Jangan
mengirim full content artikel premium ke pengguna yang tidak memiliki langganan aktif, karena konten
bisa bocor melalui inspect element atau traffic API.
canReadArticle(user, article):
  if article.access_type == "free": return true
  if user is null: return false
  return user.hasActiveSubscription()
canReadEpaper(user, epaper):
  if epaper.access_type == "free": return true
  if user is null: return false
  return user.hasActiveSubscription()

7.3 Algoritma aktivasi langganan
Payment paid
  -> validasi signature gateway
  -> cari invoice dan user
  -> cek langganan aktif
  -> jika tidak aktif: start_date = now; end_date = now + duration
  -> jika masih aktif: start_date = current_end_date; end_date = current_end_date + duration
  -> set subscription active
  -> kirim email, in-app notification, push notification
  -> redirect user ke artikel/e-paper yang sebelumnya dikunci
7.4 Catatan Play Store dan App Store
 - Pembelian konten digital dalam aplikasi Android harus disiapkan dengan Google Play Billing sesuai
 aturan toko aplikasi.
- Pembelian konten digital dalam aplikasi iOS harus disiapkan dengan Apple In-App Purchase/StoreKit.
 - Website tetap dapat memakai payment gateway lokal, tetapi tombol dan alur pembayaran di dalam
 aplikasi harus dikaji agar tidak ditolak saat review toko aplikasi.
- Product ID Android dan iOS harus disimpan di tabel subscription_packages agar paket web, Android,
 dan iOS tetap sinkron.

8. E-Paper, Mode Baca, Watermark, dan Download
8.1 Alur upload dan pemrosesan PDF
Admin upload PDF
  -> validasi file PDF dan ukuran
  -> simpan PDF asli di private object storage
  -> status epaper = processing
  -> queue ProcessEpaperPdfJob
  -> generate cover dan thumbnail tiap halaman
  -> hitung page_count
  -> admin input daftar artikel mode baca
  -> admin publish edisi
  -> pelanggan bisa membaca e-paper dan mode artikel
8.2 Acuan e-paper aktual
E-paper aktual yang digunakan sebagai acuan visual berisi 8 halaman, tanggal Senin 29 Juni 2026,
dengan halaman utama bertajuk besar "Latsarmil Kopdes Didesak Dihentikan", rubrik Kabupaten
Magelang pada halaman 2, Metropolis pada halaman 4, Wonosobo Ekspres pada halaman 5, Koran
Sekolah pada halaman 6, serta Purworejo-Temanggung pada halaman 8. Struktur ini harus didukung
oleh sistem e-paper berbasis halaman dan daftar artikel.
8.3 Fitur viewer e-paper
 - Swipe halaman kiri-kanan.
 - Zoom in dan zoom out.
 - Thumbnail per halaman.
 - Lompat halaman menggunakan page selector.
 - Mode landscape.
 - Mode malam jika diperlukan.
 - Bottom sheet daftar artikel.
 - Tombol mode artikel.
 - Tombol download PDF untuk pelanggan aktif.
 - Indikator halaman, misalnya 1/8.
 
8.4 Download PDF aman
 - Hanya pelanggan aktif yang bisa download.
 - File PDF memakai watermark dinamis berisi email user, tanggal, dan waktu download.
 - Link download menggunakan signed URL dengan masa berlaku terbatas.
 - Sistem mencatat download_logs untuk audit.
 - Batas download harian dapat diterapkan, misalnya 5 kali per hari per edisi.
 - PDF asli tidak pernah diletakkan sebagai URL publik permanen.
